# Contributing to BeatScript

We welcome contributions from musicians, developers, and sound designers!

## Personas

- **Musicians:** Share your `.beat` compositions in the `examples/` directory.
- **Developers:** Help us improve the Rust `cosmos` engine or the React `web` studio.
- **Sound Designers:** Contribute new synth types or FX chain presets to the core library.

## Getting Started

1. **Web Studio:**
   - `cd beatscript-web`
   - `npm install`
   - `npm run dev`
2. **Rust Engine:**
   - `cd beatscript-cosmos`
   - `cargo run`
   - *Prerequisites: ALSA headers (Linux), CoreAudio (macOS).*

## Code Style

- **Rust:** Follow `clippy` and `rustfmt`.
- **TypeScript:** Use functional components and Tailwind for styling.
- **Documentation:** Update `LANGUAGE_SPEC.md` if adding new syntax.
